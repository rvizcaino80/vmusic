COMO ESCRIBIR COMMITS PARA SALSAMANIA
=====================================

PASO 1: Escribe el tipo de cambio
-----------------------------------
feat     = Nueva funcionalidad
fix      = Correccion de bug
perf     = Mejora de rendimiento
refactor = Cambio interno del codigo
docs     = Documentacion (se ignora)
chore    = Tareas de mantenimiento (se ignora)

PASO 2: Agrega [user-facing] si es visible al usuario
------------------------------------------------------
Solo los commits con [user-facing] aparecen en el changelog.

EJEMPLOS QUE VAN AL CHANGELOG:
------------------------------
git commit -m "feat: [user-facing] agregar boton de favoritos"
git commit -m "fix: [user-facing] corregir error al reproducir mp3"
git commit -m "perf: [user-facing] optimizar carga de biblioteca"
git commit -m "refactor: [user-facing] simplificar logica del reproductor"

EJEMPLOS QUE NO VAN AL CHANGELOG:
---------------------------------
git commit -m "feat: agregar validacion interna"
git commit -m "fix: corregir ruta del script"
git commit -m "chore: actualizar dependencias"
git commit -m "docs: actualizar README"

REGLAS
------
- Usa ESPAÑOL siempre
- Sin mayuscula al inicio
- Maximo 70 caracteres
- Sin punto final

LISTO!
======
Con esto el release script generara el changelog automaticamente.
